# Nail It – Privacy Policy site

Det här är en fristående integritetssida för **Nail It / Blubb Gaming**.
Den innehåller ingen koppling till Trollisar.

## Innan publicering

Integritetskontakt är redan ifylld som `blubb.gaming.ab@gmail.com`.

## Publicera gratis med GitHub Pages

1. Logga in på GitHub.
2. Skapa ett nytt PUBLIC repository, exempelvis `nail-it-privacy`.
3. Ladda upp `index.html` och `.nojekyll`.
4. Öppna repositoryts **Settings**.
5. Välj **Pages** i vänstermenyn.
6. Under **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
7. Klicka **Save**.
8. Vänta någon minut. GitHub visar sedan den publika adressen.

Adressen blir normalt:

`https://DITT-GITHUB-NAMN.github.io/nail-it-privacy/`

Använd exakt den adressen som:
- Privacy policy URL i Google AdMob
- Privacy policy URL i Google Play Console
- Länk från Nail It-appen

## Viktigt

cookies eller andra tredjepartsskript.
